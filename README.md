# 团队抽签

一个无需登录的网页版团队随机选择工具，适合会议发言、任务分配和小组汇报排序。名单只存放在使用者当前浏览器的本地存储中，不会上传服务器。

## 能做什么

- 录入多个小组，并批量粘贴成员姓名。
- 全员抽人：所有小组成员混合后随机抽取。
- 指定组抽人：仅在某个小组中抽取。
- 抽小组：随机决定哪个小组先来。
- 先抽组，再抽人：先选中小组，再选中其中一名成员。
- 生成完整顺序：一次排出全部有效员工或全部有效小组的先后次序。
- 默认同一轮不重复；可切换为允许重复，并可随时重置本轮。
- 点击姓名可以临时暂停缺席成员，名单本身不会被删除。
- 可粘贴表格中的“小组、姓名”两列名单，支持表头、合并单元格空白续行和带引号 CSV，也可下载 UTF-8 CSV 备份。
- 投屏模式会隐藏编辑区并放大当前结果。

## 本地运行

不需要安装依赖。进入项目目录后运行：

```bash
npm test
npm run serve
```

然后打开 <http://127.0.0.1:4173>。

## 使用方式

1. 填写小组名称，在成员框内粘贴姓名。换行、逗号、顿号和分号都可分隔成员。
2. 选择抽签方式和抽取数量。
3. 点击“开始抽签”。页面使用浏览器的 Web Crypto 安全随机源在动画开始前计算结果。
4. 连续抽取时，默认会避开本轮已抽中的成员或小组；点击“重置本轮”即可恢复全部候选。
5. 名单、设置、本轮历史和已抽对象都会在刷新后恢复。暂停成员、修改组名、重复导入保留本轮记录；新增成员可参与，只有“重置本轮”或“清空名单”清除记录。

## 抽签与导入规则

- 导入先预览再确认。可识别两列正序或反序表头、空白小组续行、CSV 引号、单元格换行；额外列和未闭合引号会阻止导入并说明原因。无表头时默认第一列小组、第二列姓名。
- 单元格换行按多名成员识别并提示；带逗号的姓名用引号保留，例如 `"Smith, John"`。
- 无论是否允许重复，每次抽中都会记入本轮记录；关闭重复后避开本轮所有已抽对象。
- 完整顺序为独立排序：包含所有有效成员，不受已抽记录限制，也不修改已抽记录。
- 新结果保存姓名与所属小组的快照；旧版记录缺失的小组信息无法补回。
- 投屏支持继续抽签；长名单可以滚动。先抽组再抽人分两步揭晓，系统减少动态效果开启时直接展示结果。

## 数据与隐私

- 名单仅通过浏览器 `localStorage` 保存在本机。
- 没有账号、后端、分析脚本或网络请求。
- 清除浏览器站点数据或点击“清空名单”会移除保存的名单。
