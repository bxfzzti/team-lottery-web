# 团队抽签

**下一位，交给随机。**

会议发言、任务分配、小组汇报。录入名单，一次抽人、抽组，或排出完整顺序。

[打开工具](https://bxfzzti.github.io/team-lottery-web/) · [个人项目集](https://bxfzzti.github.io/) · [完整技术说明](README.technical.md)

</div>

## 可以做什么

- **五种抽取方式**：全员、指定组、抽小组、先组后人，以及完整排序。
- **同一轮不重复**：保留本轮记录，可暂停缺席成员，也可开启允许重复。
- **为现场准备**：粘贴两列表格导入名单，下载CSV备份，切换投屏显示。

## 怎么开始

1. 录入小组和成员，或粘贴表格中的两列名单。
2. 选择抽取方式、人数和是否允许重复。
3. 开始抽签，按需展示结果、复制或生成完整顺序。


## 当前范围

使用浏览器Web Crypto随机源。不同模式的抽样单位不同：先抽组再抽人时，各有效小组机会相同。

## 数据与隐私

名单和本轮状态保存在当前浏览器localStorage，不上传服务器。清除站点数据会清空记录。
