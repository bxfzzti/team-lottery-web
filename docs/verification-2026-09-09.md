# 导入及抽签修复验收

本轮修复覆盖导入漏人/分错组、临时操作重置进度、历史展示、重复模式切换与长名单投屏。

自动化测试覆盖表头正反序、扩展表头、空白姓名行更新组别、多余列报错、未闭合引号、带引号换行、带逗号姓名往返、基础随机抽取及本地存储。

Chromium 真实交互验证：

- 多余列预览错误会禁用确认导入；反序表头正确导入。
- 抽签期间重置按钮禁用。
- 暂停成员、改组名、刷新保留历史。
- 清空名单后显示空历史。
- 开启重复抽到唯一成员，再关闭重复，开始按钮禁用。
- 重复导入相同名单不恢复已抽资格。
- 投屏内继续抽取，先显示小组再显示成员；耗尽后按钮禁用。
- 84 人完整顺序在 390px 宽度投屏时结果区域可滚动，页面宽度仍为 390px。

范围：本轮未运行 Safari/Firefox、多标签并发或浏览器存储异常注入测试。
